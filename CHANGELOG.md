# История изменений — ГОРИЗОНТ Life Tracker

## [4.1.1] — 2026-06-25

### 🎨 UX / UI — крупный рефактор навигации и эргономики

#### Реорганизация навигации
- **Сократили нижние табы с 9 до 5**: Главная · Тренировка · Дневник · НЕЙРО · Ещё.
  Все остальные разделы (Задачи, Питание, Календарь, Будильник, Статы, Настройки)
  теперь открываются из экрана «Ещё» — сетка из 6 крупных карточек 2×3 с
  иконками и описаниями. Это решило проблему переполнения таб-бара на маленьких
  экранах и сделало основные действия доступными большим пальцем одной руки.
- Высота таб-бара 64 (было 62), отступы увеличены для лучшей попадаемости.
- Иконки табов увеличены до 22px (было 20), шрифт лейблов до 9 (было 7.5).

#### Новый SettingsScreen (вынесен из StatsScreen → Профиль)
- Все настройки в одном месте, сгруппированы в 6 раскрывающихся секций:
  1. **Внешний вид** — 8 тем + 7 стилей интерфейса
  2. **Профиль** — максимум отжиманий с быстрыми +/-
  3. **AI-ментор (НЕЙРО)** — провайдер, модель, API-ключ (с скрытием),
     endpoint, пресеты персонажей, доп. системный промпт, проверка соединения
  4. **Будильник** — синхронизация, тест сигнала, сброс уведомлений, открытие
     настроек Android
  5. **Данные** — экспорт в JSON, сброс всех данных
  6. **О приложении** — версия, технологии
- Секции раскрываются/сворачиваются тапом — экономит скролл на длинных экранах.

#### Dashboard — быстрые действия и план дня
- Добавлен блок **«Быстрые действия»** с 3 крупными кнопками: Тренировка,
  Дневник, НЕЙРО. Каждая кнопка показывает актуальный статус (сегодняшняя
  тренировка, есть ли запись в дневнике, AI-совет).
- Добавлена карточка **«Сегодня»** с планом тренировки на текущий день:
  показывает название, количество упражнений, и кнопку НАЧАТЬ/ПРОДОЛЖИТЬ.
  Карточка скрывается в день отдыха.
- Все тач-зоны на дашборде получили hitSlop для лучшей попадаемости.

#### MentorScreen (AI-чат) — удобство и история
- **Long-press на сообщениях** открывает контекстное меню: Копировать (через
  системный Share), Перегенерировать (для последнего ответа AI), Удалить, ✕.
- **Date separators** в чате: «Сегодня», «Вчера», или полная дата — сообщения
  визуально сгруппированы по дням.
- Кнопка настроек в шапке чата теперь ведёт на новый SettingsScreen (одна
  точка правды для всех настроек AI).
- Статус-индикатор в шапке показывает: провайдер · модель · ✓/⚠ ключ.
- Контекстный drawer «Что видит ИИ» показывает сводку данных пользователя.

#### JournalScreen — timeline и фильтры
- **Timeline view**: записи группируются по датам с заголовками «Сегодня»,
  «Вчера», «Понедельник, 15 июня» и т.д. Каждый заголовок показывает
  количество записей за день.
- **Фильтр по настроению**: горизонтальный скролл с чипами «Все» + 5
  настроений. Тап по чипу фильтрует список.
- Поиск улучшен: placeholder «Поиск по записям…», высота 42 (было 38).
- Empty state более информативный: разные сообщения для пустого дневника и
  для «ничего не найдено» по фильтру.

#### AlarmScreen — haptics feedback
- Добавлены haptics (вибрация) на ключевые действия:
  - Сохранение будильника — notification success
  - Переключение тумблера — light impact
  - Удаление — medium impact

#### TasksScreen — haptics feedback
- Переключение задачи даёт light impact haptic.

### 🛠 Технические улучшения

#### Новый модуль `src/haptics.ts`
- Централизованный wrapper над expo-haptics с готовыми паттернами:
  `Haptic.tap`, `Haptic.toggle`, `Haptic.save`, `Haptic.delete`,
  `Haptic.success`, `Haptic.warn`, `Haptic.error`.
- Молча no-op на платформах без haptics.

#### TypeScript
- Исправлена типизация `aiConfig` в MentorScreen (раньше был `{}`).
- 0 ошибок TypeScript в изменённых файлах (1 pre-existing ошибка в MentorScreen
  была и в v4.0, не критична).

#### Сборка APK
- Настроена локальная сборка через `expo prebuild` + `gradle assembleRelease`.
- Использован JDK 17 (Temurin) — JDK 21 не имеет `jlink`, нужного для
  transformation android.jar.
- Android SDK 34 + build-tools 33.0.2 + NDK 26.1.10909125.
- В `gradle.properties` увеличен heap до 3 GB, включены parallel + caching.

### 📦 Архив
- Версия 4.1.1 (patch-bump относительно 4.1.0 — UI-улучшения без breaking changes).
- Полный архив проекта без `node_modules/` и `android/` (генерируется через
  `npx expo prebuild`).

## [4.1.0] — 2026-06-25

### 🐛 Критический фикс будильника
- Все ID уведомлений получили префиксы `hz-alarm-` / `hz-snooze-`.
- На каждом старте приложения запускается **self-healing**:
  `syncAlarmsWithSystem()` отменяет orphaned-уведомления и перепланирует все
  активные будильники из хранилища.
- При первом запуске новой версии — `purgeAllAlarms()` (полная очистка).
- `deleteAlarm` теперь **await'ит** `cancelAlarmById`.
- Snooze/Stop-обработчики регистрируются один раз на старте приложения.

### ✨ Новые функции
- «Проверить сигнал» — тест будильника через 10 секунд.
- «Сбросить все уведомления» — panic-кнопка.
- «Синхронизировать» в шапке AlarmScreen.
- Превью «следующий будильник через X ч Y мин» на дашборде и в AlarmScreen.
- Экспорт данных в JSON (через expo-sharing).
- Диагностическая карточка с инструкцией.

### 🎨 UI/UX
- Переработан AlarmScreen (тач-зоны ≥44×44, hitSlop'ы, sticky-бар сохранения).
- Новые компоненты `IconBtn` и `Sheet`.
- Улучшены `Btn`/`Card`/`EmptyState`.

### 🏗 Архитектура
- Создан `tsconfig.json` (раньше не было).
- 0 ошибок TypeScript в изменённых файлах.
- Добавлены permissions `SCHEDULE_EXACT_ALARM`, `USE_EXACT_ALARM`,
  `WAKE_LOCK`, `RECEIVE_BOOT_COMPLETED` в `app.json`.

## [4.2.0] — 2026-06-25

### 🎭 Кардинальная переработка интерфейса: 5 режимов

Полностью переработанная система визуальных режимов. Каждый режим — это не
просто смена цветов, а **совершенно другой визуальный язык** со своими фонами,
карточками, кнопками и интерактивными элементами. Переключение в реальном
времени через Настройки → Внешний вид → Режим интерфейса.

#### 1. ◇ Фокус (Минимализм)
- Вдохновлён: Linear, Notion, Things 3
- Тонкая сетка из точек на фоне
- Чистые карточки с минимальной границей
- Чёрно-белая типографика с одним акцентом
- Для серьёзных пользователей, любящих чистоту

#### 2. 🌌 Аврора (Glassmorphism)
- Вдохновлён: iOS 18, Apple Vision Pro
- **Анимированные градиентные блобы** на фоне (3 блоба, двигаются с разной
  скоростью 18-30 сек)
- **Glassmorphism карточки** через `expo-blur` (BlurView с intensity 40)
- Полупрозрачные заголовки
- Плавные скругления (radius 22)
- Для пользователей, любящих современный iOS-стиль

#### 3. ⚡ Неон (Cyberpunk)
- Вдохновлён: Vercel dark, киберпанк-игры
- **Движущаяся сетка** на фоне (вертикальные + горизонтальные линии,
  анимированный сдвиг 12 сек)
- **Свечение карточек** (box-shadow с цветом primary)
- Острые углы (radius 4)
- Префикс `> ` в заголовках, расширенный letterSpacing
- Glow-эффект на primary-кнопках
- Для технарей и любителей tech-виба

#### 4. 📜 Бумага (Дневник)
- Вдохновлён: Bear, Day One, рукописные дневники
- **Тёплый градиент** с текстурой шума (80 точек)
- Карточки с **лёгким случайным наклоном** (0.3°) для органичности
- Скруглённые формы (radius 18)
- Курсивный подзаголовок
- Полу-bold шрифт для кнопок
- Для творческих пользователей, ведущих дневник

#### 5. ⚔️ Квест (Геймификация)
- Вдохновлён: Habitica, RPG-игры
- **Анимированные звёзды** на фоне (25 мерцающих точек 4 цветов)
- **Золотые углы** на каждой карточке (4 угла с золотой обводкой)
- **XP-бар** вверху дашборда (level = streak/7, прогресс до следующего уровня)
- Жирная обводка карточек (borderWidth 2, цвет warn)
- Префикс `⚜ ` в заголовках
- Для игровых пользователей, мотивируемых достижениями

### 🎨 Live Preview в настройках
В Настройки → Внешний вид добавлен блок превью 100×100 с реальным фоном и
карточкой выбранного режима. Пользователь видит как будет выглядеть интерфейс
до применения.

### 🛠 Технические улучшения
- Новый модуль `src/modes/index.tsx` (380+ строк) с системой режимов:
  - `UIMode` interface с 15 параметрами
  - 5 фоновых компонентов с анимациями (Animated API)
  - `ModeBackground` — диспетчер фонов
  - `ModeCard` — drop-in замена Card с поддержкой blur/glow/tilt/corners
  - `ModeBtn` — drop-in замена Btn с режим-специфичной стилизацией
  - `ModeHeader` — заголовок с режим-специфичным префиксом и типографикой
  - `XPBar` — опыт-бар для quest-режима
- Добавлены зависимости: `expo-linear-gradient`, `expo-blur`
- Все 9 экранов + MoreScreen обновлены для использования `ModeBackground`
- `uiMode` добавлен в `AppState`, `DEFAULTS`, `types.ts`
- `AppContext` экспортирует `uiMode: UIModeId`
- 0 ошибок TypeScript в новых файлах

### 📦 Совместимость
- Expo SDK 51, React Native 0.74.5 — без изменений
- Существующие данные пользователя сохраняются (uiMode по умолчанию = 'focus')
- Все предыдущие функции (будильник, AI, экспорт) работают во всех режимах
