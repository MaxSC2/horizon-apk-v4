```typescript
AppState {
  // Личное
  user: { name, maxPushups, note, lifeAreas[], reminderTime, reminderEnabled }
  themeId: string          // 'cosmos' | 'aurora' | ...
  uiStyleId: string        // 'default' | 'rpg' | 'kawaii' | 'pixel' | ...
  onboarded: boolean

  // Тренировки
  history: Record<dateStr, WorkoutLog>  // ключ = 'YYYY-MM-DD'
  customPlan: PlanDay[] | null

  // Задачи / цели
  tasks: Task[]

  bodyLog: BodyMeasurement[]

  // Дополнительно
  achievements: string[]
  aiHistory: ChatMessage[]
  aiConfig: AIConfig
  focus: { text, date }
  alarms: Alarm[]
  calEvents: CalEvent[]

  // Стрик (кэш)
  streak: number
}

// Отдельные ключи AsyncStorage:
// 'hz_nutrition'  — Record<dateStr, { entries: NutritionEntry[] }>
// 'hz_photos'     — ProgressPhoto[]
```

#### 2.2 Quick Check-in (ФИКСИРУЕМ БАГ)
**Проблема:** скрывается после первого тапа  
**Решение:**
```
Состояние: localMood + localEnergy (null по умолчанию)
Показ: !checkinDone (checkinDone = оба сохранены)
Шаги: выбор настроения → выбор энергии → кнопка Сохранить
Кнопка "Сохранить" видна только когда localMood && localEnergy
При сохранении: запись в journal[today], checkinDone = true
Новый день: checkinDone сбрасывается (сравниваем date)
```
- [ ] Шаг 1: выбор настроения (5 больших эмодзи-кнопок с текстом)

## ТЕХНИЧЕСКИЕ ОГРАНИЧЕНИЯ

- **AsyncStorage**: макс ~6MB на ключ. Фото → отдельный ключ, ограничение 20шт
- **Notifee**: требует настройку в AndroidManifest (EAS builds делают это автоматически)
- **React Native SVG**: НЕ использовать `Svg.Circle`, только `import { Circle } from 'react-native-svg'`
- **TextInput controlled**: для числового ввода времени использовать `defaultValue` + ref
- **Modal на Android**: `StatusBar` может перекрываться — использовать `StatusBar.currentHeight`
- **Gemini free tier**: только `gemini-2.5-flash`. Остальные требуют оплату.
