# ГОРИЗОНТ — Полная спецификация дизайна для APK

## 1. ОБЩАЯ КОНЦЕПЦИЯ

**Стиль:** Тёмный mobile-first интерфейс, минимализм, функциональность прежде всего.  
**Шрифты:** `Barlow Condensed` (заголовки, числа, лейблы) + `Barlow` (текст, описания).  
**Сетка:** maxWidth 480px по центру, padding 14px по бокам.  
**Скругления:** карточки 14px, кнопки 10px, модалки 22px (верх), чипы 20px.  
**Анимации:** transition 150-200ms ease, модалки slide up 250ms.

---

## 2. СИСТЕМА ТЕМ (8 штук)

Каждая тема содержит 7 переменных цвета:

| Переменная | Назначение |
|------------|-----------|
| `bg`   | Фон всего приложения |
| `surf` | Поверхность (шапка, навбар) |
| `card` | Карточки |
| `bord` | Границы/разделители |
| `txt`  | Основной текст |
| `muted`| Второстепенный текст, иконки неактивных вкладок |
| `lo`   | Тёмный инпут/подложка внутри карточек |

Плюс 4 акцентных: `primary` `success` `warn` `danger`

## 5. СТРАНИЦА: ГОРИЗОНТ (Dashboard)

**Скролл по вертикали, padding 14px, paddingBottom 72px.**

### 5.1 Цитата дня
- Карточка с фоном `primary`+10%, бордер `primary`+22%
- Текст цитаты: Barlow 14px italic, цвет `txt`
- Автор: Barlow Condensed 700 11px `primary`, letterSpacing 1, uppercase

### 5.2 Главный фокус дня
- Карточка с бордером `warn`+55% (если заполнен)
- Лейбл + кнопка ✏️
- В режиме редактирования: input + кнопка OK (`warn` variant)
- Текст: Barlow 15px

### 5.3 Life Score недели
- Фон градиент card→primary+8%
- Число Score: Barlow Condensed 900 38px, цвет зависит от значения (≥80 success, ≥50 warn, <50 danger)
- 3 кольца Ring: Тренировки (primary), Задачи (success), Дневник (warn)
- Таблетки: серия (warn+Flame), достижения (success+Trophy)

### 5.4 Умные инсайты (InsightsCard)
- Показывается только если есть данные
- Карточка с иконкой 💡 в лейбле
- До 3 инсайтов, каждый: иконка 28×28 rounded8 + текст 13px
- Разделены линиями bord

### 5.5 Тепловая карта (HeatMap)
- Показывается при ≥3 тренировках
- 13 недель, квадратики 13×13 gap 3, borderRadius 3
- Цвет: выполнена+сложность = opacity 0.4-1.0 от success; отдых = bord+40%; не выполнена = lo; сегодня = primary+30% + бордер primary
- Легенда: "Меньше" + 5 квадратиков + "Больше"

### 5.6 Сегодня
- Карточка с тренировкой дня: иконка, название, статус
- Быстрый лог сна: 4 кнопки 5/6/7/8 ч
- Прогресс задач дня (если есть): заголовок + прогресс-бар

### 5.7 Быстрый чек-ин
- Появляется если настроение сегодня не записано
- Фон `primary`+6%, бордер `primary`+33%
- 2 колонки: Настроение (5 эмодзи кнопок) + Энергия (5 эмодзи кнопок)
- При нажатии — сохраняет в дневник, виджет исчезает

### 5.8 Трекер воды
- 8 иконок Droplets кнопок
- Заполненные: фон `primary`+25%, бордер primary
- "Норма выполнена!" при ≥8 стаканов

### 5.9 Настроение/энергия 7 дней
- 7 колонок, каждая: эмодзи настроения + эмодзи энергии + день недели
- Пустые дни: кружок dashed bord

### 5.10 Активные цели
- До 3 карточек: иконка+название+прогресс-бар

### 5.11 Прогрессия и цитата последней записи дневника
